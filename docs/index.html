Zipcap

Catch every thought. Win Shift N, type, Enter. It lands in Notion.

Download for Windows

Windows 10 and 11 · free · open source · latest version

What it does

A small panel that opens over whatever you're doing, so a thought never has to wait for Notion to load.

Capture from anywhere

Win Shift N opens it. Enter saves the note to the bottom of your Notion page. Shift Enter adds a new line.

Tasks go to Todoist

Start with t: and it becomes a Todoist task, dates included: t: submit lab fri 8pm #Study p1

Offline? It waits

Notes are saved on your PC first and sent when you're back online. An orange dot in the tray shows something is waiting.

Install (about a minute)

No admin rights needed. It installs just for you.

  1. Download ZipcapSetup.exe and open it.

    Windows will probably warn you, because Zipcap is new and not code-signed yet. Click More info, then Run anyway.

  2. Click through the setup.

    Leave "Start Zipcap when Windows starts" ticked so Win Shift N always works. Finish launches it, and it sits in the tray (bottom right, near the clock).

  3. Connect Notion. Zipcap walks you through it.

    See the next section. You only do this once.

Connect Notion

Zipcap uses a private Notion "integration" that only you own and that can only see the one page you pick.

  1. Create the integration.

    Go to notion.so/profile/integrations → New integration. Name it "Zipcap", pick your workspace, type Internal, then save. Copy the Internal Integration Secret (it starts with ntn_) and paste it into Zipcap.

  2. Pick a page and share it with the integration.

    Open the page you want notes in (make a new one called "Inbox" if you like). Click ••• (top right) → Connections → add Zipcap.

  3. Paste the page link into Zipcap.

    ••• → Copy link, paste it, press Enter. When you see "Connected", you're done. Try Win Shift N.

Todoist (optional): the first time you type a note starting with t:, Zipcap asks for your API token. Find it in Todoist under Settings → Integrations → Developer.

Your data stays yours

Keys stay on your PC

Your Notion secret and Todoist token are encrypted with Windows (DPAPI), so only your Windows account can read them.

No servers, no tracking

Zipcap talks only to Notion, Todoist and GitHub (to check for updates). There are no analytics and no accounts.

Open source

Every line is on GitHub. You can build it yourself with one command.

Good to know

Updates

When a new version is out, Zipcap shows a note in the tray. Click it and it updates itself in a few seconds.

Change settings

Right-click the tray icon to change the Notion page, secret or Todoist token.

Uninstall

Windows Settings → Apps → Zipcap → Uninstall. To also forget your keys, delete %APPDATA%\Zipcap.
