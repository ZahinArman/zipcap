Download for Windows

Windows 10 and 11 · free · open source · latest version

What it does

Zipcap is a free quick capture app for Windows. It puts a small panel over whatever you're doing, so a thought never has to wait for Notion to load.

Capture from anywhere

Win Shift N opens it. Enter saves the note to the bottom of your Notion page. Shift Enter adds a new line.

Tasks go to Todoist

Start with t: and it becomes a Todoist task, dates included: t: submit lab fri 8pm #Study p1

Offline? It waits

Notes are saved on your PC first and sent when you're back online. An orange dot in the tray shows something is waiting.

Install (about a minute)

No admin rights needed. It installs just for you.

  1. Download ZipcapSetup.exe, open it, and click through the setup.

    Windows will probably show a red "Windows protected your PC" screen, because Zipcap is new and not code-signed yet. Click More info, then Run anyway. In the setup, leave "Start Zipcap when Windows starts" ticked so Win Shift N always works. Zipcap then lives in the tray, near the clock.

  2. Connect Notion. Zipcap walks you through it.

    See the next section. You only do this once.

Connect Notion

Zipcap uses a private Notion connection that only you own and that can only see the page you give it. Press Win Shift N and Zipcap walks you through this.

  1. Create a connection and give it your page.

    Click the link in Zipcap (or go to Notion's developer tools) → New connection. Name it "Zipcap", keep API token, then Create connection. Copy the API token (it starts with ntn_), paste it into Zipcap and press Enter. Then open the connection's Content access tab → Edit access, pick the page you want notes in, and Save.

  2. Paste the page link into Zipcap.

    Open that page in Notion → Share → Copy link. Paste it into Zipcap and press Enter. When you see "Connected", you're done.

  3. Try it.

    Press Win Shift N anywhere, type a thought, press Enter. It shows up at the bottom of your page.

Todoist (optional): the first time you type a note starting with t:, Zipcap asks for your API token. Find it in Todoist under Settings → Integrations → Developer.

Your data stays yours

Keys stay on your PC

Your Notion token and Todoist token are encrypted with Windows (DPAPI), so only your Windows account can read them.

No servers, no tracking

Zipcap talks only to Notion, Todoist and GitHub (to check for updates). There are no analytics and no accounts.

Open source

Every line is on GitHub. You can build it yourself with one command.

Good to know

Updates

When a new version is out, Zipcap shows a note in the tray. Click it and it updates itself in a few seconds.

Change settings

Right-click the tray icon to change the Notion page, Notion token or Todoist token.

Uninstall

Windows Settings → Apps → Zipcap → Uninstall. To also forget your keys, delete %APPDATA%\Zipcap.
